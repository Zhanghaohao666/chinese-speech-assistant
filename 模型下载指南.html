模型下载指南 · 下载哪个，就使用哪个

程序包不含模型。下面链接均指向官方发布源；点击后由浏览器下载。ASR 和对齐模型可保存到任意可写目录，再在软件“模型管理”中选择所在目录。

  1. 选择一种识别引擎。Qwen 需要额外下载 ForcedAligner；SenseVoice 与 FireRed 无需 Qwen 对齐器。
  2. SenseVoice 解压 tar.bz2（必要时分两层解压）；Qwen / FireRed 下载列表中的所有必需文件，放入同一个模型目录。不要把网页保存成权重，也不要使用 Git LFS 指针文件。
  3. 打开 EXE → 模型管理 → 选择本地目录 → 检查缓存。显示齐备后回到工作台，选择对应引擎并转写。

缺失文件会在界面中列出。只检查文件名不代表模型校验或推理成功。首次安装默认关闭说话人分析；需要该功能再下载最后一项。下载后可断网使用。

文件放置示例

Qwen ASR 与对齐器分别放在独立文件夹；不要放到同一个文件夹覆盖配置。SenseVoice 选择解压后的内层目录。说话人分段包内 model.onnx 必须改名 segmentation.onnx，声纹文件必须改名 embedding.onnx。

如果放在程序 models 目录之外，在对应模型卡片中选择自己的目录即可。无需复制到程序内部。
