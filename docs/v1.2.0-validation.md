# v1.2.0 发布验证

验证日期：2026-10-13。Maximalism 界面和蓝绿麦克风图标版本。

## 真实推理

使用同一段 42.12 秒中文会议录音，在包含中文及空格的独立便携目录运行交付包内的 Python；隔离开发环境路径，模型从本地缓存显式选择。测试时禁用 Hugging Face 联网。原始输出、音频和会议内容仅保存在本地，不随公开仓库发布。

环境：Windows 11 x64，AMD Ryzen 9 7945HX，NVIDIA RTX 4070 Laptop 8 GB，CPython 3.12.4，PySide6 6.9.2，PyTorch 2.7.1+cu126。

| 模型 | 实际设备 / 精度 | 任务耗时 | 结果 |
|---|---|---:|---|
| SenseVoiceSmall / sherpa-onnx | CPU / INT8 | 6.44 秒（含说话人分析） | 成功 |
| FireRedASR2-AED | CUDA / BF16 | 23.38 秒 | 成功 |
| Qwen3-ASR-1.7B + ForcedAligner-0.6B | CUDA / BF16 | 33.48 秒（含对齐） | 成功 |

耗时为应用记录的端到端任务时间；不同模型所需辅助阶段不同，不作为严格性能排名。三个任务顺序执行，前一 worker 结束后才启动下一模型。每个模型的 TXT、DOCX、PDF、SRT、VTT、JSON 六种导出均成功；检查 DOCX ZIP 完整性、PDF 文件头、字幕格式标识及阅读文本内容。

## 功能验证

- 72 项回归测试和 8 个子测试通过。
- 文件选择导入、剪贴板文件导入、拖放导入通过。Qt 对话框在自动测试中返回真实文件路径，拖放发送实际 Qt 事件。
- 无模型时阻止启动任务并转到模型下载入口；各引擎本地目录选择通过。
- 三模型切换、任务进度、后台结束后的控件恢复通过。
- 阅读 / 字幕切换、文本编辑、搜索、项目保存和重新打开、历史记录恢复通过。
- 真实音频播放 / 暂停、进度跳转、倍速、正文跟随定位通过（测试静音）。
- 实际 worker 取消通过；故意损坏的 WAV 触发预期解码失败，失败状态及重新导入后的恢复通过。
- 原生 EXE 启动器此前已实际启动检查；此次推理使用同一交付包内的隔离运行环境与代码。
- 已检查多尺寸与 Qt 125% / 150% 缩放布局，主要正文与操作文字对比度不低于 4.5:1。

## 测试工具退出复核

首次自动测试完成全部断言后，测试进程退出时发生原生异常。最小复现确认：仅创建 offscreen Qt 剪贴板并设置测试 QMimeData，也会出现同样退出异常；空白应用关闭正常。测试脚本清理自己创建的剪贴板后，完整功能复核退出码为 0。没有为此修改产品代码或清空真实用户剪贴板。

## 范围与限制

此次验证未发现阻断发布的问题，不代表没有任何缺陷。没有在另一台实体电脑实测，也没有重跑长音频或 Qwen / FireRed 的 CPU 路径；本轮结果仅覆盖上述设备与 42 秒样本。没有进行人工逐字准确率评分或说话人准确率评测。

SenseVoice 的块时间与 token 起点不能当作精确句子起止；FireRed 使用自身 CTC 时间，失效时明确退回块时间，尚未接入标点模型。会议摘要功能仍未接入。

发行包包含 EXE 启动器、独立 Python 和 CPU / GPU 依赖，不包含模型权重、录音、转写内容、历史记录或用户配置。下载模型后在“模型管理”选择本地目录；必须保留 EXE 同目录的 runtime、src 等文件。
