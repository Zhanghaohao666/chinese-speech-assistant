# Maximalism v1.2.0

- 原生 PySide6 / QSS / QPainter 实现，无新增组件库、字体下载或识别依赖。
- 用户提供的蓝绿麦克风 PNG 原样保留，并转换成 16–256 px 的 Windows ICO；启动器、窗口、侧栏与空白页同步更新。
- 奶油色点阵底、红黄青紫主题、粗描边、叠层卡片、贴纸式装饰；转写正文保持白底和深色文字。
- 全局覆盖工作台、历史、模型、设置、控件与弹窗；纪要未接入状态保持真实。
- 1440×900、1280×800、1024×640、854×534 逻辑尺寸及 125% / 150% Qt 缩放检查；小窗口优先保留正文。
- 三个 ASR、时间来源、手动下载模型、编辑与导出流程保持原实现。未额外引入摘要能力。
- 不含模型权重、录音、个人配置。重新选择已下载的模型目录即可复用缓存。

截图中的“界面演示”内容是布局样例，不是新一次识别测试。
